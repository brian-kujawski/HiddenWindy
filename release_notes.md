HiddenWindy Release Notes v0.1

Welcome to the initial release of HiddenWindy, an Android app custom-developed to assist you as you play Jet Lag: The Game: Hide + Seek in Chicago, IL!

Notes:

* Intended play area is all of Cook County, IL.
* This is Seeker-focused. Hiders can absolutely use it to help answer questions or even visualize the Seeker's zone, but it's by no means necessary.
* I have, and will continue to, put in effort to find and fix bugs, and I've added the ability to disable and re-enable questions without penalty if anything is borked. That said, I've only had so much QA time and suggest Seekers take the time to make physical backups with pen and ruler on paper maps when able.

Features:

* Layers:

 - Overlay the datasets used for the questions on your map.
 - POIs were pulled from the OpenStreetMaps API in early July 2026. There is no live-polling.
 - Rather than worrying about Google's search where it might serve you a Wendy's when looking for the nearest park, you can reference these markers instead.

* Questions:

 - Select from a list of questions available for use in a medium-sized game of Hide + Seek.
 - Matching, Measuring, Thermometer, Radar, and Photos are implemented completely.
 - Tentacles are not yet implemented, largely because they're never used in the Jet Lag games and were an easy drop for v0.1.
 - When you select a question, the app will generate a text message you can copy-paste into Signal to share with the Hider. The text contains all of the information they need to answer your question.
 - A timer is available for your convenience, as a reminder of how long the Hider has to answer that type of question.
 - When you receive a reply, you will be able to resolve the question based on their response. For example, yes, the hider says they're within my 5 mile radar!
 - Based on your resolution, the map will automatically shade the excluded hiding zone, helping you narrow in on the Hider's location.
 - Note that Photos are reproduced here for convenience only, there is no in-built way to see your Hider's photos when they reply back.

* Rules:

 - Review the rules for the base game and the expansion cards.
 - These are here for quick reference, but are identical to the rules in the printed book. If you find a discrepancy, trust the book.
 - A search bar is available so you can quickly find the relevant rule. It is a dead-simple dumb search, so don't expect it to help you out too much if you can't remember how to spell the card name or etc.

* History:

 - View a log of all the questions you have asked so far in this game.
 - If you made an error with your question, you can Disable said question. Disabling removes its overlay from the map and frees up the question to be asked again.
 - Questions are not deleted, only disabled. Historical questions are retained without limit until you start a new game. This history has been tested to several dozen questions but there is no set limit on how many times you could disable and repeat a question. If you do so and the app breaks, well, consider not doing so.

* New Game

 - Delete the question history, wipe the map clean, start over.
